Agent Manifest Diplomat

Registration gateway for Agent Manifest declarations.

The Diplomat receives an Agent Manifest declaration, checks its structure against the published v1.0 JSON Schema, refuses a duplicate agent_id, and records what it accepts in the public dataset. That is the whole of its job.

It exists so that publishing a declaration does not require a pull request. The Ambassador helps someone write a manifest and submits it here; the dataset keeps the record and the registry index makes it resolvable.

The endpoint

One route, which accepts POST only. A browser visiting it will be refused.

POST https://agent-manifest-diplomat.vercel.app/api/register

What it does not do

  • It does not authenticate anyone. A manifest is not signed and proves nothing about who submitted it.
  • It does not certify, accredit, or issue any mark.
  • It does not authorise an agent to do anything, and grants no permission of any kind.
  • It does not enforce, observe, or constrain how a declared agent then behaves.
  • Acceptance means a document was well formed. It is not a statement about the agent that published it.
